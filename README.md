# Website Profil Guru PAI — Supriyaningsih, S.Pd.I. (SDI Al-Firdaus)

Website portofolio dan profil resmi pendidik profesional **Ibu Supriyaningsih, S.Pd.I.**, Guru Pendidikan Agama Islam (PAI) & Budi Pekerti bersertifikasi di **SD Islam (SDI) Al-Firdaus**.

## Fitur Utama
- **Identitas & Sertifikasi Pendidik**: Menampilkan kualifikasi akademik `S.Pd.I.`, status **Guru Bersertifikasi**, satuan pendidikan **SDI Al-Firdaus**, serta 4 pilar kompetensi guru profesional.
- **5 Pilar Pembelajaran PAI Interaktif**: Filter kategori materi (Al-Qur'an & Hadits, Aqidah & Akhlak, Fiqih Ibadah, dan Sejarah Kebudayaan Islam).
- **Program Pembiasaan Keagamaan**: Ringkasan kegiatan rutin Islami di SDI Al-Firdaus.
- **Pojok Doa Harian Siswa**: Modul interaktif doa pilihan beserta teks Arab, transliterasi Latin, arti, dan pesan pendidik.
- **Ganti Foto Profil Instan**: Tombol unggah foto langsung pada halaman atau ganti file `assets/avatar-guru.jpg`.
- **Konsultasi Wali Murid & Cetak Portofolio**: Formulir pesan silaturahmi otomatis ke WhatsApp/Clipboard serta mode cetak rapi (`Ctrl + P`).

## Cara Menjalankan
Buka file `index.html` langsung menggunakan browser (Chrome, Edge, Firefox), atau jalankan server lokal di folder proyek ini.

## Kustomisasi Nomor WhatsApp
Buka `script.js` dan isi konstanta `TEACHER_WHATSAPP` pada baris pertama (contoh: `"6281234567890"`).
